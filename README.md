💸 Peso Split App
Split shared costs and show who owes whom.

Made by: Ashley H. Santiago
Section: BSINTE - 2A
School: Nueva Vizcaya State University

Description
A simple mobile app for splitting bills with friends

Features
•  Add Bill Name
•  Enter Total Amount
•  Add Friends
•  Tip Calculator
•  Automatic Calculation per Person
•  Shows Who Owes Whom
•  Bill History

How to Install and Run
1.  Download this code
2.  Open in FlutterFlow or VS Code
3.  Run flutter pub get
4.  Run flutter run
